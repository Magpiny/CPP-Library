nodiscardconstexpr

Calculate the area of a polygon using the Shoelace theorem.

Template Parameters
TThe floating point type for calculations
Parameters
verticesThe vertices of the polygon in order (clockwise or counter-clockwise)
Returns
Area of the polygon, or std::nullopt if invalid

The Shoelace theorem (also known as the surveyor's formula) calculates the area of a simple polygon given the coordinates of its vertices: Area = 0.5 * |Σ(x_i * y_{i+1} - x_{i+1} * y_i)|

Calculate area of a regular polygon (all sides equal, all angles equal).

Template Parameters
TThe floating point type for calculations
Parameters
num_sidesNumber of sides (must be >= 3)
side_lengthLength of each side
Returns
Area of the regular polygon, or std::nullopt if invalid

Formula: Area = (n * s²) / (4 * tan(π/n)) where n = number of sides, s = side length
